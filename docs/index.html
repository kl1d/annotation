Run locally

Simple Docker startup

1. Clone the repository

git clone https://github.com/kl1d/annotation.git
cd annotation

2. Start the app

docker compose up --build

3. Open the local workspace

Frontend: http://localhost:5173
API:      http://localhost:8000/api

Docs

Reusable app, study-specific setup

The application is open source and reusable across studies, while project config, raw assets, and normalized outputs stay local to each research workflow.

  • project/config/*.example.yaml provides reusable templates
  • real local config files are copied from templates and ignored by Git
  • project/assets/ and project/data/ remain local to the study machine
  • GitHub Pages hosts this landing/docs site, not the Docker app itself
